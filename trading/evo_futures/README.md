# 合约策略进化记录（第 1 轮，5 代）

- 交易所 / 品种：OKX USDT 永续合约，BTC、ETH、SOL、BNB、XRP，1 小时 K 线，逐仓
- 杠杆：策略自己决定，范围 1~10 倍
- 训练区间：2024-02-01 ~ 2025-06-01（进化过程中只看这一段）
- 验证区间：2025-06-01 ~ 2026-11-01（只在最后跑了一次，结果没有用来再改策略）
- 打分：`fitness = 收益% − 1.5 × 最大回撤%`；初始资金 1000 USDT，最多同时 3 单
- 资金费率：OKX 只提供最近约 3 个月的数据，更早的部分按每期 0.01% 估算（配置里的 `futures_funding_rate`）
- 每一代的策略由 Claude Code 在会话里直接编写（没有用 API），用 `evolve/score.py` 回测打分；所有记录见 `history.jsonl`

## 结论

1. 相比种子策略进步很大：顺势过滤加上按波动率自动调杠杆，把“必亏”变成了“接近持平”。
2. 但**训练集里的优势在验证集上基本消失**：前 4 名里 3 个在验证集小亏，最好的 G4_C2 也只有 +3%，
   回撤 16%，信号很弱。**这些策略都不适合实盘。**
3. 有效的方向：只顺大趋势做单；按波动率自动调杠杆，能把回撤降一半。
   无效的方向：通道突破、紧的 ATR 止损、移动止盈、去掉阶梯止盈。
4. 下一轮建议：加一段更新的数据作为最终测试集；试 4h 周期（手续费占比更低）；
   给 G4_C2 做 hyperopt 后再到验证集看一次；加入资金费率、持仓量等合约特有的数据。
